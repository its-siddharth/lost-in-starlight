# Lost in Starlight Website

A cinematic, anime-inspired website for the film "Lost in Starlight".

## Features
- **Hero Section**: immersive background with Netflix-style metadata.
- **Image Grid**: Asymmetrical layout showcasing key scenes.
- **Dynamic Gallery**: Auto-loads images from the assets folder.
- **Lightbox**: Fullscreen image viewer for gallery items.
- **Responsive Design**: Works on desktop and mobile.

## Setup & Run

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```
   Open the link shown in the terminal (usually `http://localhost:5173`).

## Project Structure
- `index.html`: Main HTML structure.
- `style.css`: Global styles and animations.
- `main.js`: Gallery logic and Lightbox implementation.
- `assets/lost-in-starlight-gallery/`: Images source.

## tech Stack
- Vanilla JavaScript
- CSS3 (Variables, Grid, Flexbox)
- Vite (Build tool)
